The Sorting Hat resolves every name through its scope and checks every operand before a single instruction is conjured; the Room of Requirement then runs ten passes over the intermediate code until nothing more can be taken away. Both show their working, line by line — and when a verdict needs explaining, the oracle speaks.

II

The Sorting Hat — type checker

Names resolve through a chain of scopes; every expression is given a type from the bottom up and held against what its surroundings demand. Mismatches, narrowing conversions, const violations, ill-fitting arguments and conditions that cannot be tested for truth are all caught here, before any code is conjured.

III

The Room of Requirement — optimizer

The sorted tree is lowered into three-address code, and then ten passes run again and again until the instruction stream stops changing, because each pass uncovers work for the others. Every rewrite below is recorded with what it replaced and why the replacement is safe.

The Pensieve — target code
